# 🐾 Huellapet

Este proyecto corresponde al trabajo final del curso de Frontend.

Consiste en una landing page que presenta una propuesta digital para el control y cuidado de la salud de mascotas.

-----------------------------------------------------------------------------------------------------------------

 ## 📌 Descripción

Huellapet es una plataforma pensada para ayudar a los usuarios a organizar la información importante de sus mascotas, como:

* Datos generales (nombre, raza, edad, etc.)
* Control de vacunas y desparasitación
* Registro de visitas al veterinario
* Seguimiento de cuidados básicos

-----------------------------------------------------------------------------------------------------------------

## 🧱 Estructura

La página está organizada en las siguientes secciones:

* Header con navegación
* Sección principal (hero)
* Funciones
* Beneficios
* Galería
* Formulario de contacto
* Footer

-----------------------------------------------------------------------------------------------------------------

 ## 🛠️ Tecnologías utilizadas

* HTML5
* CSS3
* Flexbox y Grid
* Diseño responsive
